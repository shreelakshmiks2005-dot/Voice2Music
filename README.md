# Voice2Music
## Required Downloads

### Model Checkpoints
Download the pretrained models here:

- [PerformanceRNN checkpoint](http://download.magenta.tensorflow.org/models/performance_with_dynamics.mag)
- [MusicVAE checkpoint](https://storage.googleapis.com/magentadata/models/music_vae/checkpoints/hierdec-trio_16bar.tar)

### FluidSynth
Install FluidSynth (required for MIDI rendering) from the official site:

- [FluidSynth Windows binaries](https://github.com/FluidSynth/fluidsynth/wiki/Download)
